# rtcmd

`rtcmd` 用于向内核/驱动提供的设备节点 `/dev/remote_cmd` 写入一段命令字符串，实现“远程命令”或运行时控制。

## 构建

在 `arprj/apps/utils` 顶层执行 `make` 会自动构建；或在本目录执行：

- `make`
- `make clean`

## 运行

### 基本用法

```sh
./rtcmd <cmd...>
```

程序会把从 `argv[1]` 开始的所有参数拼接成一个字符串（每段后加空格），然后写入 `/dev/remote_cmd`。

### 示例

```sh
./rtcmd foo bar baz
```

实际发送到设备节点的字符串类似：

- `"foo bar baz "`（末尾有一个空格）

## 前置条件

- 系统中存在 `/dev/remote_cmd`，并且对应驱动/模块已加载。

## 注意事项

- 本工具会 `fork()` 子进程执行发送（父进程直接返回）。
- 单次命令总长度限制 `1024` 字节（包含末尾 `\0`）。
