# ar_top

`ar_top` 是一个面向平台的线程/调度统计工具，用于读取 `/proc/<pid>/task/*/status` 中的统计信息并计算一段时间窗口内的运行/调度差值，最终按运行时间排序输出。

> 该工具不是标准 Linux `top`，更偏向对线程调度/运行时间的采样统计。

## 构建

在 `arprj/apps/utils` 顶层执行 `make` 会自动构建；或在本目录执行：

- `make`
- `make clean`

## 运行

### 查看帮助

```sh
./ar_top --help
```

参数（来自 `show_help()`）：

- `--time <ms>`: 刷新/采样间隔，默认 `1000`ms
- `--sch_time <us>`: 刷新/采样间隔（微秒，源码中有该参数但实际用法以实现为准）
- `--pid <pid>`: 需要统计的进程 PID（必填）

### 示例

统计 PID=1234 进程，每 1 秒刷新一次：

```sh
./ar_top --pid 1234 --time 1000
```

## 输出

程序会输出包含线程名、运行时间差、调度次数差、CPU 占用估算等信息的表格（字段名见源码打印）。

## 注意事项

- 依赖 `/proc` 提供的 `status` 字段格式；如果系统裁剪了字段，可能解析失败。
- 当目标 PID 不存在或没有权限读取 `/proc/<pid>/task` 时会退出。
