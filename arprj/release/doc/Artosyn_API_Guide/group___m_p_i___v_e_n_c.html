AR_S32 AR_MPI_VENC_AttachVbPool ( VENC_CHN  VeChn,
const VENC_CHN_POOL_S *  pstPool 
)

将编码通道绑定到某个视频缓存VB池中。

注解
目前只支持使用VENC_CHN_POOL_S中的hPicVbPool，此vb pool中最小的buffer数量为2，
每块buffer的size计算方法为：align32(width)*align32(height) + align16(align32(width)/2)*align32(height)
参数
[in]VeChn: 通道号
[in]pstPool: 视频缓存VB池的Id号。
返回值
0: 成功。
non-zero: 失败，其值为错误码。
