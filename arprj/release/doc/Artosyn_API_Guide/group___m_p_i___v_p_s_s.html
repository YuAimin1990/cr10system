设置延迟启动VPSS处理的延时队列长度。延时处理主要由于前端进来的图像通过PCI传到主片可能会有延迟，为了保持同步，VPSS通过delay队列让主片的图像也延迟一段时间；另一应用场景是用户从VI获取图像，再通过TDE模块画框，该帧同时又送给VPSS进行处理，由于VPSS处理速度比TDE快，因此需要VPSS进行延迟处理

参数
[in]VpssGrpVPSS GROUP号。取值范围：[0, VPSS_MAX_GRP_NUM)
[in]u32Delay延时队列长度。取值范围：[0, 5]
返回值
